Política de privacidade — Agente Estúdio

Última atualização: 2 de novembro de 2026

Quem usa

O Agente Estúdio é um aplicativo pessoal, usado apenas pelo seu dono, Jonathan, nos próprios canais do YouTube. Não há outros usuários.

Que dados acessa

Com a autorização do dono pelo login do Google, o aplicativo lê, somente para leitura, dados dos próprios canais: lista de vídeos, estatísticas do YouTube Analytics e comentários públicos dos vídeos. Ele não publica, não altera e não apaga nada no YouTube.

Como os dados são usados e guardados

Os dados ficam apenas no computador do dono, para relatórios internos de desempenho e ideias de conteúdo. Não são vendidos, compartilhados nem enviados a terceiros, e não são usados para publicidade. O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados locais podem ser apagados pelo dono no próprio computador.
